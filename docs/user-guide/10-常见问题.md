# 10 常见问题

按使用者真实会问的顺序排。

## 取名结果相关

**一个名字为什么不在结果里？** 按这五件事逐一排查，基本都能定位：

1. 两个字是否都在名用字白名单（293 字）里。不在就整条不会进池子——自选页可以自己挑这种字，但生成页不会出。
2. 第一个字是否落在这一句的音步起点上。同一个词若在句中位置不对，就不会被取出来。
3. 第二个字是否与第一个字在**同一个句读**里、间隔不超过 3。跨句读的搭配一律不取。
4. 是否被你自己的设置挡住了：典籍开关关掉了那一部、拉黑名单里有它、禁用字含它的字、性别风格选了偏男而它是反向名（中性名不受影响，"疑似"名要勾"含疑似"才进来）。
5. 是不是被现代高频成词规则剔掉了（jieba 词频 ≥ 5000 直接剔除，例如"明白"）。

**为什么"这个条件下没有剩余候选"？** 页面给的排查顺序就是有效顺序：清空搜索 → 篇名点"不限篇" → 指定字点"不限"或改位置 → 禁用字点"不限" → 放宽笔画 / 常见度 / 结构。剩下两种可能是典籍全选关，或者候选都已拉黑。

**"同篇还有 N 条"点进去比 N 少？** 不会。这个数按当前筛选命中的候选池算（`plan()` 与池子同一趟算出），设了禁用字、性别或典籍开关之后，按钮上的数就是点进去以后的数。

**分数是什么？为什么同一个名字换个姓分数不一样？** 分数是若干可解释加减项之和，展开卡片上的"分数明细"能逐项看到。它会随姓与姓氏读音变化，因为音韵与谐音检查是拿"姓 + 名字"一起算的。**分数只用于这 1,525 条内部的排序，不是对名字好坏的评价。** 想换尺子就用排序里的"笔画少""用字常见度""按出处"。

**卡片上的"常见度"是重名率吗？** 不是。它是依据 114 万条真实姓名去姓后的用字频次做的估算，界面也写着"不是户籍重名率"。重名率查询这个功能整个项目都不做——国内没有可靠的公开接口，宁可不做也不编数字。

**为什么有的字没有部首？能不能顺便看五行？** 卡片上的"部首"讲的是《康熙字典》部首归属，只覆盖木 / 火 / 水 / 金 / 土 五部中查得到的 63 个字（1,525 条双名里 553 条至少一个字可标注）。没标注不代表它不属这五部、也不代表它没有五行。五行筛选、八字、五格、吉凶、"补缺"建议一概不做——不可核对的判断不做，是这个项目的边界。

**单字名为什么很多没有出处？** 217 个单字名里有 76 个没有典籍出处。它们仍可收藏（有出处的能回查），但界面上不会给原句与今译。

## 数据与备份相关

**换手机 / 换浏览器后收藏不见了。** 收藏存在本机 `localStorage`，不同步、不上传。用"导出"存一份 JSON，在新设备上"导入"，选"保留两边"（合并）或"覆盖"。定期导一份出来当备份是稳妥做法；浏览器清空站点数据等于清空收藏。

**导入失败，几种说法分别什么意思？**

| 界面上的说法 | 原因 |
|---|---|
| 这个文件不是 JSON，读不出内容 | 文件本身不是合法 JSON 或不是对象 |
| 这个文件里没有本应用的记录，认不出它是哪里导出的 | `app` 字段不是 `naming-app`，或者没有任何本应用字段 |
| 这个文件里没有可导入的东西（收藏、拉黑、筛选设置都是空的） | 是本应用导的，但三项全空 |
| 这个文件超过 8 MiB 的上限 | 体积门禁。选文件时先拒一次，读出来之后按实际字节再判一次。本应用自己导出的一份最大的（全量候选）约 0.6 MiB，离这条线很远 |
| 这个文件读不出来（可能被浏览器拦下，或选完就被移走了） | 读取本身失败，重新选一次 |

前三种都不会弹出"合并 / 覆盖"对话框，也不会动你已有的收藏。

**CSV 在 Excel 里某些格子前面多了一个引号 / 我用 Google Sheets 打开看见一个 `'`。** 那是防公式执行的前导单引号：单元格以 `=`、`+`、`-`、`@` 打头时导出会加它，避免 Excel / WPS 把内容当公式跑一遍。Excel / WPS 打开时不显示这个引号；LibreOffice、Google Sheets、pandas 会照原样给你。宁可多一个可见的引号，也不让你手打的备注被执行。

**字段里的换行哪去了？** 被压成空格。一个字段塞进换行会凭空多出一行 CSV，所以导出前统一压平。

**收藏里有一条显示"在当前候选池里已经对不上任何条目"。** 它是旧版本收录过、或者语料换过之后留下的记录。这一类会单独列出，卡上只保留当时记下的名字与出处，不能重新打分，分数也可能与当初收藏时不同。要清掉就逐条取消收藏。

## 界面与设备相关

**深色模式不跟着系统变。** 检查主题是否选在"跟随系统"（存在 `naming.theme.v1`）。选"跟随系统"时随系统偏好实时切换；选浅色或深色就是固定。页面加载时会先按已存偏好上色，避免深色下闪一下白底。

**离线时打不开 / 装了以后还是旧版。** 首次安装需要联网一次，之后离线可用。有新版本时页面顶部提示"有新版本可用"，点它或刷新即可取新版。刷新时会给等待中的 worker 发 `SKIP_WAITING`。导航请求走 network-first，所以部署新版后刷新即取到新页面。

**离线时页面提示"数据都来自本机缓存，功能正常"。** 这是正常状态，不是错误。

**手机上按钮太小、页面横向要拖动？** 320 px 宽度起无横向溢出，宽度小于 1024 px 时交互目标不小于 44 px，平板宽度（768 px）同样按触摸尺寸算。这些由 40 组"设计体检"实测把关（5 视口 × 深浅主题 × 4 页面），有硬违规时构建直接失败。

**分享卡提示"二维码没画出来（链接过长）"。** 当前页面地址太长时二维码容量不够。这条反馈会明说画没画出来，不会静默给你一张不能用的图。

**"有新版本可用"没提示，但确实有新版本。** 提示要求同时存在等待中的新 worker 和旧版控制权。首次访问只有新 worker 时不提示——那时没有旧版本可换。

**能不能把当前筛选固定成一个链接给别人？** 可以，点"复制链接"。链接只编码筛选条件（姓、读音、性别、是否含疑似、字数、搜索词、排序、笔画上限、常见度下限、典籍开关、禁用字等），不含收藏与拉黑。链接里出现某一项，这一项就进入状态；取值不可信时回该项默认值，不夹到边界也不静默丢弃；链接里没有的项沿用对方本机已存的偏好。

**姓是生僻字或只有一个汉字？** 姓只保留汉字、最多两字。姓的首字是多音字时上方会出现读音下拉框，务必选对——它影响读音标注、谐音核对和排序。姓不在读音表（通用规范汉字表 8,105 字）内时，页面会明确告诉你音韵那一侧的检查没跑。生僻汉字（扩展 A 区、兼容区里的字）不会被静默删掉。

**我的数据会被上传吗？** 不会。运行时零网络请求，没有账号、没有统计脚本，收藏与拉黑只存在你这台设备的浏览器里。

## 想扩展它

**能加别的典籍吗？** 能，但要同时改五处：语料与指纹清单、构建脚本的取词参数、典籍顺序常量、门禁的语料规模与出处断言、界面文案里的典籍计数。而且体积预算先撞线的是站点产物那条（当前余量 5.0%，按每条双名 73.3 B gzip 算约 280 条双名就撞线）。

**能加一个想用的字吗？** 能，走白名单扩表流程：`node scripts/l0-unlock.mjs` 生成待审表 → 人工逐字判定写进 `data/raw/l0-verdicts.txt` → `npm run build`。门禁会切到下界断言，已有候选不允许消失。详见 [04 数据与语料](04-数据与语料.md)。
