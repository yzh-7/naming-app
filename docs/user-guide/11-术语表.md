# 11 术语表

按"从使用者到维护者"的顺序排，每个词只讲它在这个项目里指什么。

## 取词与候选

| 术语 | 指什么 |
|---|---|
| 典籍 / 语料 | 七部书：诗经、楚辞、论语、水墨唐诗、宋词三百首、道法（22 行手工录入）、乐府诗集（20 篇） |
| 句读 | 取词的工作单位。原文先按 `。！？；` 分句，再按 `，、：` 分句读，去标点。取词的两个字必须落在同一个句读里 |
| 取词段 | 一个句读里参与取词的那段文字，是统计口径里的最小单位（全库 23,133 段、101,805 字） |
| 音步 / 音步起点 | 名字第一个字必须落在的位置，按诗体配置（四言取第 1、3 字这类位置，骚体五字取 0 与 3）。它是"解释"不是"事实"：词与散文没有固定节奏，起点退化为"全取" |
| `strict` | 标记这一条是不是按固定节奏取出来的。false 时界面写"宽口径取词：长短句 / 散文 / 道法，务必看原句" |
| 间隔 / `gap` | 两个取词字的位置距离：1 是相邻，2 是中间隔 1 个字，3 是中间隔 2 个字。卡片上的说法是"中间隔 N 字"。口径上限是 gap ≤ 3 |
| 跨字取词 | `gap > 1` 的取法，卡片上标"跨字取词，看原文自辨"，分数上也各扣 4 分 / 8 分 |
| Pool-B / 候选池 | 按上述口径取出来的双名集合，当前 1,525 条（间隔 1 / 2 / 3 = 727 / 474 / 324）。它是发布出去的那一份 |
| Pool-C | 把白名单放宽到全部规范汉字后可取的搭配数（51,959 条）。**只是池内计数，没有发布**，随包体积的天花板先撞线 |
| 单字名层 / singles | 217 个单字名，其中 76 个没有典籍出处 |
| 叠字 | 典籍里的重叠构词（依依、燕燕、昭昭）。相邻重复字保留为叠字，"假叠字"剔除；"只看典籍叠字"筛选只作用于双名层 |
| 名句层 `famous` | 原句属于这本书的名句，打分 +8 |
| 出处 / 原句 / 今译 | 出处是"典籍 + 篇名 + 作者"；原句是取词所在的那一句；今译是本项目自撰的白话释义（1,140 行，只解释句意，不增补典故、不做命理） |
| 候选编号 | 形如 `Bsj_caiwei_yiyi_001`：层级 + 典籍代号 + 篇名 + 名字去声调拼音 + 序号。序号按"篇 + 去声调拼音"前缀计数，所以池子扩容时旧编号不位移。收藏与拉黑按完整编号存 |
| 前缀碰撞 | 同篇同音不同字共用前缀（《诗经·采薇》"依依"与"翼翼"都是 `yiyi`）。当前 1,524 个前缀里 1 组 2 条，完整编号仍唯一，且这项统计由门禁独立重算对账 |

## 用字与打分

| 术语 | 指什么 |
|---|---|
| L0 / 名用字白名单 | 293 个字：268 字种子（cnname 属性表全部用字 ∩《通用规范汉字表》一二三级 8,105 字）+ 25 字人工判定保留。取词的两个字都必须在里面 |
| `l0-verdicts.txt` | 人工判定为"保留"的字清单，单独校验文本指纹，不在 `SHA256SUMS` 里 |
| 下界断言 | 扩表之后门禁换的断言方式：已有候选不允许消失，用来防止扩表把旧名字弄丢 |
| 虚词 / 忌讳字 / 噪声词 | 三道减法里的排除项。现代高频成词按 jieba 词频 ≥ 5000 直接剔除（例如"明白"） |
| 同形风险 | 名字与现代词同形。词频 500 以上记进条目的 `risk` 并在打分里扣 12 分；与高频词同形扣 40 分。这张表按"人工补录 + 频率阈值只做初筛"维护 |
| 谐音 / 简拼谐音 | 连读形成某个词扣 20 分；姓与名字的首字母拼出来撞词扣 12 分 |
| 用字常见度 | 依据 114 万条真实姓名去姓后的用字计数（2,240 个字、211 万次用字）换算的档位：很常见 ≥8000、常见 ≥2000、一般 ≥500、少见 ≥100、冷僻 <100。是估算，不是户籍重名率 |
| 部首提示 | 该字的《康熙字典》部首落在木 / 火 / 水 / 金 / 土 五部中的哪一部（63 字可标注）。**不是五行归属判断**，不进打分、不做筛选 |
| 结构 / 字形 | 八类结构名：独体、品字、上下、上中下、左右、左中右、全包围、半包围。"避开同结构"筛选排除两字同结构的名字，叠字不判为同结构 |
| 分数 / 分数明细 | 若干可解释加减项之和（详见 [03 名字是怎么来的](03-名字是怎么来的.md)）。只用于候选池内排序，不构成对名字优劣的评价 |
| 性别风格：强 / 疑似 | 强 = 每个字都指向同一侧；疑似 = 只有一个字命中、其余字在两表之外。卡片标签四态：偏男、偏女、中性、疑似 |

## 数据与版本

| 术语 | 指什么 |
|---|---|
| `data/raw/` | 上游语料、字表、派生输入、许可全文、`SHA256SUMS` 的所在地。要改数据就改这里 |
| `src/data/` | `npm run build:data` 生成的产物（候选、字表、今译、白名单、风险表、meta）。**不要手工编辑** |
| 语料指纹 `corpus_sha` | `data/raw/SHA256SUMS` 的 SHA-256 前 12 位（当前 `b30924ef5d04`），页脚显示。清单里任何一份原始文件变了，它即变 |
| 应用版本 | 只有一个来源：`package.json` 的 `version`（当前 0.3.1），注入页脚、页面 meta、Service Worker 注册参数三个出口 |
| 标签（tag） | `v0.1.0` 这类注释标签，规则是打在"`version` 第一次取该值的提交" |
| minor / patch | 语料口径变或新增用户可见功能 → 升 minor；只修缺陷 / 只收紧门禁 / 只补许可与类型强度但产物字节变 → 升 patch；只动测试、门禁配置与文档、产物逐字节不变 → 不升 |
| "未发版"段 | 版本号没升但已随 `main` 部署的那一批改动，记在 `CHANGELOG.md` 开头 |

## 工程与门禁

| 术语 | 指什么 |
|---|---|
| 门禁 | 构建链上任何一环失败即构建失败的检查集合：形态检查、数据校验、类型检查、lint、带阈值的测试、构建、体积检查 |
| `verify.mjs` | 数据门禁：输入指纹、白名单账目、出处自洽、单字名覆盖、今译覆盖率、五部标注、性别表规模、编号前缀碰撞对账 |
| `size-check.mjs` | 体积门禁：非 HTML 资源 gzip 合计 ≤400 KiB；HTML 按产物形态取预算（页面壳 400 KiB、单文件产物 450 KiB）。两条都进退出码 |
| gzip 口径（CI / 本机） | 同一份文件的 gzip 结果与压缩实现有关：CI 的官方 Node 自带 zlib-ng，本机是系统 zlib，当前差 1.4%。门禁按较大的一侧算 |
| 覆盖率阈值 | 行 91% / 语句 90% / 函数 90% / 分支 83%，任一条低于即失败。分母只算 `src/` 下自撰的可执行代码 |
| 设计体检 `audit:design` | 5 视口 × 深浅主题 × 4 页面共 40 组的实测：横向溢出、触控目标尺寸、文字对比度、方块字行长、页头是否遮挡首屏卡片。五条硬违规之一出现即退出码 1 |
| 端到端（e2e） | Playwright 在真实浏览器里跑关键路径，28 个用例，含 axe 扫描 |
| axe / WCAG | 可访问性自动扫描，按 WCAG 2 A/AA 判 |
| `aria-pressed` | 状态按钮（收藏、拉黑、主题、只看叠字）用它表达"按下 / 未按下"，不改文案 |
| 变异抽查 | 在临时副本里逐条改坏生产代码，看指定用例是否变红。用来判断断言是否真的有效（覆盖率高 ≠ 用例有效） |
| 收敛（sanitize） | 把不可信输入（本机存储、导入文件、链接参数）归一化的那一份规则：`sanitizeOpts`、`sanitizeReading`、`cleanSurname`、`cleanAvoid`、`isHan`。口径是"不可信就回该项默认" |
| `isHan` | "是不是汉字"按 Unicode 的 `\p{Script=Han}` 判，覆盖基本区之外的扩展 A 区、兼容区与扩展 B 以后的字 |
| 门禁自身的用例 `tests/gates/` | 测 `verify.mjs` 与 `size-check.mjs` 的失败路径（12 条纯 Node 用例），在临时夹具里跑，不动仓库本体 |

## 分发

| 术语 | 指什么 |
|---|---|
| 站点产物 `dist/` | 发布用的产物，分三块：`vendor`（React 等依赖）、`data`（固化的语料 JSON）、`index`（业务代码）。数据块单独拆便于长期缓存 |
| 单文件版 `dist-single/` | `SINGLE=1 vite build` 打成的一个 HTML（1,678,890 B），双击即用。只用于体积核对，不发布 |
| PWA | 可安装到主屏幕、可离线打开的网页应用。本项目有 manifest、Service Worker、图标 |
| Service Worker（SW） | 负责离线缓存与"有新版本"提示的脚本。导航请求 network-first，带哈希的静态资源 cache-first，离线拿不到资源时回 504 纯文本 |
| 缓存名 `naming-app-<hash>` | 按当前部署的产物文件名哈希算出，不手工维护。取不到产物时退回 meta 里的版本号，再退回注册参数 |
| TWA | 把已托管站点包成安卓应用的方案（Bubblewrap），网页更新即应用更新，代价是首次需联网与对托管站点的依赖 |
| Capacitor | 把 `dist` 打进安卓安装包、可用系统分享与文件系统的方案。`ANDROID.md` 推荐的实施路径，但**仓库当前没有安卓代码** |
| 收敛点三条路径 | 本机存储、导入文件、分享链接。任何一条改了收敛规则，另外两条要共用同一份 |
