# 02 使用手册

四个页面：生成、自选、收藏、拉黑。页签在页头，页头是粘顶的，切换页面时会自动回到顶部。下面按页面讲，控件名用的就是界面上写的那几个字。

## 生成页（`#/`）

这是主页面。左边（手机上在上面）是筛选，右边是结果卡片，最底下一行是数据进出的按钮。

### 先填姓

姓的输入框支持复姓，最多留两个汉字，非汉字会被去掉。姓的第一个字是多音字（例如"单""曾"）时，旁边会出现"姓首字的读音"下拉框，界面写着"多音姓请选"。这个选择影响后面一切：读音标注、谐音核对、分数排序。姓如果不在读音表里（生僻姓），页面会直接告诉你"有字不在读音表（通用规范汉字表 8105 字）内，声调、谐音、生僻这些音韵检查这次没有跑"——卡片仍然出，只是那一侧的检查没做。

### 第一组控件：形态与批量

| 控件 | 作用 | 可选值 |
|---|---|---|
| 名字字数 | 只看双名或只看单名 | 双名 / 单名 |
| 性别风格 | 按性别字表收窄候选 | 不限 / 偏男 / 偏女 |
| 含疑似 | 开着时，只要有一个字在性别字表里就保留（其余字两侧都不在也算）；关着时要求每个字都指向同一侧 | 开 / 关 |
| 每批条数 | 一屏几条，也决定要翻几页 | 12 条（默认）/ 24 条 / 48 条 / 全部 N 条 |
| 换一批 | 往后翻一页 | 按钮 |

"每批条数"选"全部"时一次画完当前筛选命中的全部候选，卡片多、页面长，适合导出前先扫一眼。

性别风格用的是强弱两级判定：**强**是名字的每个字都指向同一侧，**疑似**是只有一个字命中、其余字在两表之外。卡片上的性别标签因此有四种：偏男、偏女、中性、疑似。偏男用冷色、偏女用暖色，筛选按钮和卡片同色。

### 第二组控件：查找与指定

| 控件 | 作用 | 说明 |
|---|---|---|
| 搜索 | 按名字、拼音或篇名搜 | 输入汉字或拼音都行，旁边有"清除" |
| 篇名 | 只保留这一篇里的候选 | 可以在这直接写（例如"离骚"），也可以从卡片上的"同篇还有 N 条"进来；筛选按精确匹配，不会把邻近篇名带进来 |
| 指定字 | 结果里每条名字都必须含这个字 | 只能是一个汉字；双名还能限定它"用作首字"或"用作末字" |
| 禁用字 | 名里出现其中任意一个字的候选整条不出现 | 用于避长辈名讳、家里忌讳的字。最多 8 个汉字，重复字不重复计。**只查名，不查姓**（姓是你自己的姓） |
| 排序 | 结果的排列方式 | 按分数 / 笔画少 / 用字常见度 / 按出处 |

排序选"按分数"或"按出处"时结果按典籍分组展示；选"笔画少"或"用字常见度"时保持全局顺序。

禁用字与指定字是**交集**关系：同一个字既指定又禁用，结果是 0，页面直说没有候选，不会硬凑。禁用字只作用于生成页——收藏里含这些字的条目照旧留在收藏页，页面会写一条"含禁用字的收藏有 N 条，要清掉就逐条取消收藏"，不悄悄藏起来。

### 第三组控件：高级筛选（默认收起）

| 控件 | 作用 | 可选值 |
|---|---|---|
| 整名笔画上限 | 名字两个字的笔画合计不超过这个数 | 不限 / ≤16 画 / ≤20 画 / ≤24 画 / ≤28 画 |
| 用字常见度下限 | 每个字在真实姓名里的用字频次都要够这一档 | 不限 / 排除冷僻（≥100）/ 至少一般（≥500）/ 至少常见（≥2000） |
| 避开同结构 | 排除"两字结构相同"的名字（都左右、都上下这类） | 开 / 关 |
| 典籍 | 七个开关，按书收窄 | 诗经 / 楚辞 / 论语 / 唐诗 / 宋词 / 道法 / 乐府 |
| 只看典籍叠字 | 只看典籍里的叠字（依依、燕燕、昭昭） | 开 / 关，单名层没有叠字，得先切到双名 |

筛选折叠起来时，池内计数仍然显示在明面上，看得见当前条件命中多少条。

### 卡片上有什么

卡片分四层，从上到下：

1. **名字本体**：大字衬线名字、读音与声调、性别倾向标签。
2. **出处**（常驻一行，点开看原句与今译）：典籍 + 篇名 + 作者、原句（长句会截取窗口并标"取词段第 N"，跨字取词会标"跨字取词，看原文自辨"）、今译。这是整个应用的凭据。
3. **事实**：字义（本义）、字形（笔画合计与结构）、用字常见度、多音提示、部首提示、同音写法、小名建议。
4. **警示行**：只有需要提醒时才出现，例如与高频现代词同形、连读谐音某个词、单字现代频度低。

卡片下方还有"分数明细"（默认折叠，点开能看到每一项加减各是多少）和四个动作：**收藏**、**拉黑**、**复制信息**、**分享卡**。另有"同篇还有 N 条"（这个数按当前筛选算，设了禁用字或典籍开关之后就是筛过的条数）和"按拼音看"。

小字说明：常见度是**估算**，依据 114 万条真实姓名去姓后的用字频次，不是户籍重名率。部首那一行写的是该字的《康熙字典》部首落在木 / 火 / 水 / 金 / 土 五部中的哪一部；没标注不代表它不属这五部、也不代表它没有五行——本应用不做五行筛选、不判吉凶。

### 结果为空时

页面会给出定位提示，按它给的顺序排查通常就能找到原因：清空搜索；篇名筛选点"不限篇"回到全部；指定字点"不限"或改位置；禁用字点"不限"看是不是这几个字把池子滤空了；放宽笔画 / 常见度 / 结构筛选。剩下的可能是典籍全选关，或者候选都已拉黑。

### 数据那一行

| 按钮 | 干什么 |
|---|---|
| 导出 | 把收藏、拉黑、筛选设置存成一份 JSON，用来备份或换设备 |
| 候选CSV | 把**当前筛选命中的全部候选**（不只这一屏）存成表格，Excel / WPS 可直接打开，含出处原句与今译 |
| 候选JSON | 同一份候选全量清单的 JSON 版，适合程序处理 |
| 导入 | 选一份 JSON 文件，导入前会校验，导入时问你要"保留两边（合并）"还是"覆盖" |
| 复制链接 | 复制当前页面地址。链接只编码筛选条件，不含收藏与拉黑 |

CSV 里有个细节值得知道：单元格内容以 `=`、`+`、`-`、`@` 打头时，导出会前置一个前导单引号，免得 Excel / WPS 把它当公式执行。在 Excel / WPS 里打开看不到这个引号，换 LibreOffice、Google Sheets 或 pandas 打开就会看见它。宁可多一个可见的引号，也不让你手打的备注被执行。

## 自选页（`#/compose`）

自己挑字，不走候选池的分数。先填姓，再选第 1、2 个字（也可以只选一个字，得到单名）。

挑字有两种方式：从下面的候选字表点（汉字按字找、拼音按音找，默认只列名用字表内的 293 字，关掉"仅名用字表"可以看全部 8,105 字；也可以直接输入任意汉字，用"直接使用「子归」"这类入口），或者点"随机自由组合"换一批。随机默认只在有典籍出处的搭配里随机，也可以打开"不看有无出处"。还有一条"在典籍同一句读里搭配过的字"查询：给出与某个字在典籍里配成过名字的那些字（这些搭配都取自同一个句读，每个搭配只留分数最高的那条出处），适合顺着一个字往下找。

自选页做的是**核对**，不是打分：读音与谐音、字形（笔画、结构）、有没有出处。有出处的组合显示原句与今译；没出处的组合显示"本典籍里没有这个搭配的出处"，并且**不提供收藏入口**（收藏按出处条目定位）。不在名用字表内的字会被标出来，字义与常见度可能留白，读音与谐音仍会核对。

自选页不受生成页的禁用字筛除——这是你自己挑的字。但挑到禁用字时会明说："这里照旧能组合，生成页不会出现含它的名字。"草稿存在本机（`naming.compose.v1`）。

## 收藏页（`#/fav`）

收藏支持备注、分组、分组过滤、搜索与排序。

- 搜索框按名字 / 拼音 / 备注 / 分组找。
- 排序四档：最近收藏、分数高→低、笔画少→多、用字常见度。
- 分组可以改名、可以解散。解散只删组名，组里的收藏退回未分组，不删收藏。组名最长 24 字。
- 勾 2～3 个收藏可以进对比表（第四条勾不上）。
- 数据那一行：导出 CSV（按当前搜索与分组视图导出，含"分组""备注"两列）、导出名单图、打印名单。

分数会随姓氏与读音的选择重新计算，所以同一条收藏在不同姓下分数不同。还有一类条目要单独说明：有些收藏在当前候选池里已经对不上任何条目（旧版本收录过、或者语料换过）。这类收藏会单独列出，卡上只保留当时记下的名字与出处，不能重新打分。

## 拉黑页（`#/block`）

拉黑的名字不再出现在生成结果里。这一页上点卡片的"已拉黑"就是解除入口，也能直接收藏。拉黑名单参与生成时的过滤，也随导出/导入一起走。

## 主题、离线提示与出错兜底

- **主题三档**：跟随系统 / 浅色 / 深色，常驻页头，四个页面都能切，存在 `naming.theme.v1`。选"跟随系统"时随系统偏好实时切换。四个页面、分享卡、对比表、导入弹窗都有对应的深色配色。页面加载时会先按已存偏好上色，避免深色模式下闪一下白底。
- **离线提示**：断网时页面顶部写"离线模式：数据都来自本机缓存，功能正常"。有新版本时提示"有新版本可用"，可以点"刷新"立即取新版。
- **本机存储不可用**（隐私模式或已写满）时，页面写清楚："这一页照常能用，但收藏、拉黑与筛选不会保存，关掉页面就没了。"
- **出错兜底页**：某处渲染异常时替换为该子树的兜底界面，收藏与设置仍在，刷新一般即可恢复。
- **打印**：打印样式只保留卡片正文，动作区与折叠详情不打印，卡片不跨页断开。

## 手机上的表现

320 px 宽度起没有横向溢出。视口宽度小于 1024 px 时交互目标不小于 44 px 高，平板宽度（768 px）同样按触摸尺寸算。断点是 384 / 640 / 1024 / 1280。页签在手机上整宽另起一行，主题切换在窄视口只显示图标。名字用衬线大字，界面文案用无衬线，数字用等宽数字，正文一行不超过约 40 字。这些都有实测把关，见 [06 命令、门禁与部署](06-命令、门禁与部署.md) 的"设计体检"一节。
