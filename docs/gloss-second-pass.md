改后的规模：今译字数（去掉句末标点）合计 **33,166 → 35,027 字**，平均每行 **15.0 → 15.9 字**。最长那行 225 字没变（《山鬼》的整篇合译）。

## 两条改写时定下的口径

- **用典的地名与人名字面照译，不展开典故**。例：「金谷俊游，铜驼巷陌」译作「在名园里与俊友同游，在京城街巷间漫步」，不写金谷园是谁的园、铜驼的典故是什么；「自是休文，多情多感」译作「只怪自己像休文那样多情善感」，不写成「像多病的沈约」。这与 `data/raw/LICENSES.md` 里那句「只解释句意，不增补典故与命理判断」是同一条线。
- **句末一律以「。」或「？」收尾，不用破折号，不用拉丁字母**。全表除这一版新改的以外都这样，改动必须跟表一致。

## 门禁：四条从「查出来的问题」变成「以后不许再出现」

`scripts/verify.mjs` 新增 `4k)`，逐条全表核、不是抽样：

1. 今译不许与原句一字不差；
2. 译文里不许出现繁简对照表里的繁体字（与 0.20.0 的输入归一同口径）；
3. 译文互不相同——同一句译文挂到两条原句上，必有一条是抄错的；
4. 译文一律以句末标点收尾。

`tests/gates/verify.test.mjs` 加两条失败路径用例（照抄原句判红、译文里塞繁体判红），门禁用例从 18 条涨到 **20 条**。门禁总数 370 个单元用例。
